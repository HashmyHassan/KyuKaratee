Connect KarateBiz to Google Sheets
One-time setup. Your data will sync across your PC and iPad automatically after this.
1
Create a new Google Sheet
Go to sheets.google.com and create a blank spreadsheet. Name it KarateBiz.
2
Open Apps Script
In the Sheet, click Extensions → Apps Script. Delete any existing code in the editor.
3
Paste the backend code
Open Code.gs (the other file you downloaded). Copy everything and paste it into the Apps Script editor. Click Save (disk icon).
4
Deploy as Web App
Click Deploy → New deployment → gear icon → Web app. Set Execute as: Me. Set Who has access: Anyone. Click Deploy and authorize when asked.
5
Paste your Web App URL below
Copy the Web App URL shown after deployment (starts with https://script.google.com/macros/s/…) and paste it here.
